## 代替テストの範囲

復帰通知は対象アプリのウィンドウだけに送り、OS全体への通知・入力の送信は行っていません。
実際のスリープ・ロック・画面消灯・RDP切断・セーバー登録・レジストリ変更は行っていません。

これによりアプリ内の通知処理・タイマー再開・終了処理を検証できますが、次の項目は未検証です。

- 実機ハードウェアやGPUドライバーを含むスリープ復帰
- 実際のRDP再接続
- 複数の実ディスプレイ、DPIの異なる実画面、画面の抜き差し
- Windowsの無操作時間による起動と復帰時のサインイン連携
- Windows 10、32bit Windows、ARM64環境での実行

初回配布は、この範囲を明示したプレビュー版です。

## 再実行

```powershell
cd windows-saver
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test -Package
```

テストが失敗した場合、新しいZIPは作成されません。生成される `test-results/report.txt` で失敗箇所を確認できます。
